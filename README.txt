Holo Card 更新版 — 6枚のカード

GitHub Pagesへの更新
1. ZIPを解凍します。
2. 中身を既存リポジトリの公開フォルダへアップロードしてください。
   index.html と app.js が一番上にあり、cardsフォルダも必要です。
3. GitHub Pagesの公開完了後、サイトを再読み込みします。

操作
カードをダブルタップ／ダブルクリック：全画面鑑賞
「閉じる」またはEsc：通常表示へ戻る
ドラッグ／矢印キー：カードの角度を変更
F：裏返す　R：リセット
「スマホを傾けて操作」：対応端末の傾きセンサーを有効化
「中心を合わせる」：現在の持ち方を基準にする

スマホの傾き操作はHTTPSで開いたサイトで利用してください。
iPhoneなどではボタンを押した後にセンサーの許可が必要です。
未対応端末や許可しない場合も、指による操作は使えます。
センサーの値は端末内の表示にのみ使い、送信しません。

立体表現は独立したイラスト、視差、浅い起伏、動く影によるものです。
動物を全方向から見る完全な3Dモデルではありません。
